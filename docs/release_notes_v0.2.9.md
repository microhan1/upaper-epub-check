유페이퍼(upaper.net) 업로드 전 EPUB 사전 검수기 — 창 모드 EXE (Windows 64bit).

### 바뀐 점
- **「의견 보내기」를 키보드로** — Tab 으로 「새 버전 확인」 다음에 닿고, Enter 나 Space 로 엽니다. 초점이 오면 링크 둘레에 갈색 테두리가 보입니다.
- **마우스를 올리면 설명** — 잠깐 뒤 「안 되는 것·불편한 것·바라는 기능을 알려 주세요(브라우저가 열립니다)」가 링크 아래에 뜹니다. 창을 화면 끝에 붙여도 잘리지 않습니다.
- 누르면 전처럼 책갈피 툴 페이지의 [의견 칸](https://chaekgalpi.co.kr/tools/upaperepub#feedback)이 브라우저로 열립니다. 프로그램은 페이지를 열기만 하고 따로 보내는 것은 없습니다.
- 책갈피 툴 공통 페이지 언어 규칙(한국어 화면 → 한국어 페이지, 그 밖 → 영어 페이지)을 의견 칸과 새 버전 알림에 똑같이 씁니다. 이 도구는 한국어 화면이라 열리는 페이지는 그대로입니다.

검증: 테스트 205개 통과(이번에 26개 추가 — 키보드·마우스 올림 설명·페이지 언어 규칙·네트워크 0건), 유페이퍼 승인본 오류 0(epubcheck 5.4.0 포함), EXE 를 오프라인 환경에서 띄우고 닫아 정상 종료.

### 새 버전 확인
창을 열 때 새 버전이 있는지 확인하려고 도구 이름과 버전만 책갈피 서버(chaekgalpi.co.kr)에 보냅니다. EPUB 파일은 보내지 않고, 하루 한 번만 확인하며, 창의 「새 버전 확인」 체크로 끌 수 있습니다. 자동으로 내려받거나 바꾸지 않습니다.
