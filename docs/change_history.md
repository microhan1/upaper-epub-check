## v0.2.3 (2026-09-19) — 자간 벌린 '펴 낸 날' 판권 탐지 실패 수정

### 수정
- **날짜 표기 정규식**: `펴낸날` 이 `펴낸날|펴낸\s*날` 로만 적혀 있어 판권에 흔한 자간 표기 **"펴 낸 날"** 을 못 잡았다. 같은 파일의 `펴낸곳`(`펴\s*낸\s*곳`)·`지은이`(`지\s*은\s*이`) 와 달리 날짜 표기만 글자 사이 공백을 허용하지 않던 누락. `_spaced()` 헬퍼로 `발행일·발행년월일·출간일·펴낸날`(`DATE_WORDS`)의 글자 사이 공백을 일괄 허용하도록 `DATE_LABEL`·`STRICT_DATE_LABEL` 을 재작성.
- 증상: 판권을 "펴 낸 날 / 펴 낸 곳" 식으로 적은 책에서 (1) ISBN·정가·연락처가 없으면 판권 자체를 못 찾아 COLOPHON-MISSING, (2) 찾더라도 "날짜는 있으나 '발행일/출간일' 표기가 없습니다"(COLOPHON-DATE 경고) 오탐.
- `초판`·`발행`·`출간` 처럼 짧은 낱말에는 자간 허용을 **적용하지 않았다** — "최초 판단" 이 `초\s*판` 에 걸리는 식의 본문 오탐을 막기 위함. 회귀 테스트에 케이스 있음.

### 추가
- 픽스처 `tests/make_fixtures.py: spaced_colophon_epub()` — 제목·파일명에 "판권"이 없고 항목을 전부 자간 표기로 적은 판권 페이지. 구조 신호만으로 찾아내야 한다.
- 테스트 `SpacedColophonTest`(탐지·COLOPHON-DATE 없음·오류 0), `DateLabelTest`(자간 표기 매칭, `_has_hard_datum` 단독 성립, 본문 낱말 비매칭).

### 검증
- 단위 테스트 24/24 통과. 수정 전 정규식으로 되돌리면 새 테스트가 실패함을 확인.

## v0.2.2 (2026-09-15) — 상용 EPUB 167권 테스트로 오탐 제거

### 배경
- 사용자 요청으로 `C:\Users\micro\Desktop\Books` 의 EPUB 167권(리디·교보·알라딘 등 상용본, 0.2~100MB)을 전부 검사. 36초, 프로그램 중단 0건. 그러나 표지 중복 107권·판권 중복 18권·판권 도서명 없음 31권·이미지 누락 23권은 상용본치고 비정상이라 원인을 추적.

### 수정
- **표지 중복**: "이미지 한 장짜리 문서가 앞쪽에 더 있다" 휴리스틱(경고)이 속표지·출판사 로고 페이지를 잡고 있었음 → 제거. 같은 표지 이미지를 두 문서가 쓰는 경우(오류)만 남김. 107권 → 1권(실제 중복).
- **첫 장 표지**: 첫 장이 이미지 한 장짜리 표지 페이지인데 OPF `<meta name="cover">` 와 다른 파일을 쓰면 오류가 아니라 정보(COVER-FIRST 정보 등급).
- **판권 탐지**: 키워드 개수만 세던 방식 → 구조 신호(발행일 표기·날짜·펴낸곳·저자·정가·ISBN·연락처) 점수 + 6000자 상한 + 날짜/ISBN/정가/연락처 중 하나 필수. 긴 본문 장이 판권으로 뽑히던 문제 해소.
- **판권 중복**: '확실한 판권'을 "판권 제목 또는 발행일 표기+날짜+펴낸곳+(ISBN·연락처·정가)"로 조임. 저자 소개·본문·저작권 고지 페이지 오탐 제거. 18권 → 0권.
- **날짜 정규식**: 월 1~12·일 1~31 로 제한 — 출판등록번호를 날짜로 오인하지 않음.
- **ISBN 검증**: "978-89-349-9500-5 05300" 처럼 부가기호가 붙거나 공백이 섞인 표기는 앞 13(10)자리만 검증. 상용본 60권이 검증 실패로 나오던 문제.
- **도서명 대조**: 공백·문장부호 제거 후 전체/부제 앞/가장 긴 어절 순으로 비교. 31권 → 14권(남은 것은 판권 본문에 제목이 정말 없는 책).
- **판권 후보 조건 재조정(2차, 비팅화면\Books 136권)**: 본문 장이 "2011년 8월 25일 … 이메일" 로 판권으로 뽑히던 것 → 필수 근거를 ISBN·정가·출판등록/전화·"발행 표기+날짜" 로 제한. 도서명 대조는 인접 어절 묶음(4자 이상)으로 넓혀 "김팔봉 수호지 10" ↔ "수호지 10", 괄호 부제 제목이 통과.
- **이미지 판권**: 텍스트 판권이 없고 끝부분에 이미지만 있는 페이지가 있으면 오류 대신 수동확인(COLOPHON-IMAGE).
- **CSS 폰트 누락**: CSS url() 이 가리키는 파일 없음은 IMG-MISSING 이 아니라 CSS-RES-MISSING(오류, epubcheck RSC-007 과 동일)로 분리.
- **mimetype 없음**: "첫 항목이 아님" 대신 "mimetype 파일이 없습니다" 로 정확히.
- 본문 텍스트에서 BOM/제로폭 문자(U+FEFF, U+200B) 제거 — 일부 EPUB 본문에 섞여 있어 대조가 깨졌음.

### 검증
- 단위 테스트 16/16, 회귀 기준 『하늘은 왜 파래요?』 오류 0 유지.
- 167권 재검사: COVER-DUP 1, COLOPHON-DUP 0, COLOPHON-TITLE 14, COLOPHON-MISSING 11 + COLOPHON-IMAGE 10, CSS-RES-MISSING 23(실제 폰트 파일 누락).

### 배경

### 추가
- `upaper_check/gui.py` — 더블클릭(인자 없음) 시 뜨는 창. 드롭 영역에 EPUB 을 놓으면(여러 개 가능) 즉시 검사, 결과 요약을 창에 기록, 보고서 자동 열기(체크박스) · [파일 선택…] · [보고서 열기]. 드롭은 tkinterdnd2 로 구현하고, 모듈이 없으면 파일 선택만 되는 창으로 내려간다.
- `cli.check_file_for_gui()` — 창이 쓰는 검사 함수(HTML 보고서를 EPUB 옆에 생성). 테스트 추가.
- `UPAPER_SELFTEST=1` 환경변수로 창을 만들었다 닫으며 드롭 가용 여부를 출력(배포본 점검용).

### 변경
- `upaper_check.spec` — tkinterdnd2 의 Windows 64bit tkdnd 바이너리(Tcl 8.6/9)만 datas 로 포함. `Report._summary_line` → `summary_line` 공개.
